# BOKI 商标申请标样

本目录是提交中国商标网时直接上传的图样，规格为 **1000 × 1000 px、纯白底、JPG**。

| 文件 | 用途 | 申请类型 |
|:--|:--|:--|
| `BOKI-wordmark-1000.jpg` | 上传到第 9 / 42 类的图样 | 文字商标（BOKI） |
| `BOKI-logo-1000.jpg` | 上传到第 9 / 42 类的图样 | 图形商标（黑白 logo） |
| `BOKI-wordmark-1000.png` | 备用（部分系统接受 PNG） | — |
| `BOKI-logo-1000.png` | 备用 | — |
| `BOKI-wordmark-source.svg` | 源文件，改字号/字距用 | — |
| `BOKI-logo-source.svg` | 源文件，改尺寸用 | — |

## 为什么是黑白

图形标申请**黑白（不指定颜色）**，保护范围最广：注册后可以自由更换配色使用。
如果申请彩色，则只保护申请时的那个配色。

## 上传注意

- 图样内**不要**出现「®」「™」、网址、公司名、水印。
- 白底、黑色主体、边缘清晰（本目录文件已满足）。
- 单张 JPG 控制在 200 KB 以内（当前约 23–29 KB）。
- 一次申请对应一张图样；文字标和图形标要**分开提交**。

## 重新导出

```bash
cd backend
node scripts/export-trademark.mjs
```

输出会覆盖本目录的 4 个成品文件。
