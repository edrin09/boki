# BOKI 知识产权与商标注册方案

> **定稿：品牌名 BOKI（全大写），纯英文单品牌，不设中文名。**
> 商标只注册 **BOKI 文字标 + 图形标**；"簿记"仅作为词源说明，不作为品牌、不申请。
>
> 对标 DBX 的结论：DBX 公开信息**未显示注册商标**（官网页脚无 ®、README 无商标声明、仓库无 TRADEMARK 文件），许可证为 **Apache-2.0**。我们学它的开源运营，但**商标要比它做得更规范**。
>
> 核心策略：**先提交申请锁定"申请日"，开发与开源并行推进，不等拿证。**

## 二、先决条件：个体户资格与经营范围

### 2.1 资格

个体户**可以**申请商标。自然人申请商标必须提交《个体工商户营业执照》，你的执照就是资格证明。

两种申请名义（二选一，全程保持一致）：

| 名义 | 写法 | 适合 |
|:--|:--|:--|
| **字号名义** | 营业执照登记的字号 | 更像品牌主体 |
| **经营者名义** | 执照登记的经营者姓名 | 材料更简单 |

> ⚠️ 申请书、委托书、图样上的申请人名称必须**完全一致**，否则会被要求补正。

### 2.2 经营范围（最容易卡住的一步）

申请的商品/服务应与执照经营范围**相关**，实践中会审查。

| 类别 | 经营范围最好包含 |
|:--|:--|
| 第 9 类（软件） | 软件开发、计算机软件销售 |
| 第 42 类（SaaS/开发） | 软件开发、信息技术服务、技术服务 |
| 第 35 类（会计服务，可选） | 会计、财务咨询、代理记账 |

**动作**：先看执照。范围不够 → 先办经营范围变更（通常 1–3 个工作日），再提交商标。

### 2.3 2026 新规

使用**新版个体工商户营业执照**的，还需提交从登记机关指定网站下载打印的**经营范围证明**（申请人/代理机构签章确认真实有效）。

## 三、注册全流程（8 步）

### Step 0｜准备材料（1–2 天）

- [ ] 个体工商户营业执照（清晰扫描件）
- [ ] 经营者身份证正反面
- [ ] 手机号、常用邮箱
- [ ] 商标图样（JPG，纯白底，建议 ≥1000×1000px，清晰）
- [ ] 经营范围证明（新版执照需要）
- [ ] （如委托）代理委托书

**标样准备**（用现有品牌资产导出）：

| 标样 | 源文件 | 申请样式 |
|:--|:--|:--|
| **BOKI 文字标** | `brand/boki-wordmark.svg` | 全大写 `BOKI`，黑白，白底 |
| **图形标** | `brand/boki-mark-mono.svg` | **黑白**单色 logo，白底 |
| 组合标（可选） | `brand/boki-lockup.svg` | 文字 + 图形组合，黑白 |

> 💡 **重要**：图形标建议申请**黑白（不指定颜色）**。黑白商标的保护范围更广，可以自由改配色使用；申请彩色商标则只保护该配色。

### Step 1｜商标检索（1–3 天）

- [ ] 中国商标网（sbj.cnipa.gov.cn）免费检索
- [ ] 检索词：`BOKI`、`boki`、近似拼写
- [ ] 类别：第 9、42、（35）类
- [ ] 查看状态：已注册 / 申请中 / 驳回 / 无效
- [ ] 重点看**近似**，不只完全相同
- [ ] 建议让正规代理出一次**近似检索报告**（几百元，避免 12 个月白等）

**输出**：可注册性结论 + 需规避的近似商标清单。

### Step 2｜确定申请方案（1 天）

- [ ] 标样：BOKI 文字标 + 图形标（+ 组合标可选）
- [ ] 类别：**9 + 42**（核心）；预算允许加 **35**（会计服务）
- [ ] 每类选 **10 个商品/服务项目**（官费内含 10 个）
- [ ] 一标多类提交（官费按类累加）
- [ ] 自行申请 or 委托代理

### Step 3｜提交申请（1 天）

**方式 A：自行网上申请**
1. 中国商标网 → 商标网上服务系统 → 注册账号（审核约 3–5 个工作日）
2. 登录 → 商标注册申请 → 填写申请人信息
3. 选择类别 → 勾选商品/服务项目 → 上传图样
4. 提交 → 在线缴费（270 元/类）
5. 保存申请号与回执

**方式 B：委托代理（首次推荐）**
- 优点：处理补正、近似判断、材料规范；缺点：多付代理费。
- 确认代理是**备案正规代理机构**。

### Step 4｜形式审查 → 受理（约 1 个月）

- 下发《受理通知书》（电子）
- 材料有问题 → 补正通知，**30 天内**补正
- ✅ 拿到受理通知书后，即可正常使用品牌并开源发布

### Step 5｜实质审查（法定 9 个月内，通常 4–9 个月）

审查三件事：**显著性、近似、禁用条款**。

| 结果 | 应对 |
|:--|:--|
| 全部通过 | 进入初审公告 |
| 部分驳回 | 放弃被驳回项目，或申请复审 |
| 全部驳回 | 收到通知 **15 日内**申请**驳回复审** |

### Step 6｜初审公告（3 个月）

- 公告期内任何人可提**异议**
- 被异议 → 收到通知后 **30 日内**答辩
- 无异议或异议不成立 → 核准注册

### Step 7｜注册公告 → 发证（约 1 个月）

- 电子《商标注册证》
- 有效期 **10 年**，自核准注册之日起算

### Step 8｜注册后维护

- [ ] 留存使用证据（合同、发票、官网、GitHub Release）
- [ ] 连续 **3 年不使用**可被"撤三"，保持真实使用
- [ ] 到期前 **12 个月**续展，宽展期 6 个月
- [ ] 名称/地址变更及时办理变更
- [ ] 许可/转让及时备案

## 六、与开发并行的排期

> 核心逻辑：**提交日 = 申请日**，锁定后开发/开源可以立刻推进，不用等拿证。

| 阶段 | 商标线 | 开发线（v2.0） |
|:--|:--|:--|
| **D0–D7** | 查经营范围 → 免费检索 → 定标样/类别 | 内核边界划分 |
| **D7** | **提交 9/42（+35）申请，锁定申请日** | 插件运行时 + SDK 骨架 |
| **W1–M1** | 等受理通知书 | 主题/i18n 运行时 |
| **M1–M2** | 受理 | 试点插件（解析器 / 报表） |
| **M2–M6** | 实质审查 | 插件市场 + 批量迁移 |
| **M6–M9** | 审查结果 | AI 插件化 |
| **M9–M10** | 初审公告（3 个月） | 开源首发 + 社区运营 |
| **M10–M12** | 注册公告 → 发证 | 品牌全面启用 ® |

**并行时的注意事项**

1. **提交前**：不要大规模付费投放品牌广告（万一驳回，沉没成本高）。
2. **提交后**：可立即开源发布、写 README、上官网——申请日已锁定。
3. **拿证前**：标注用 `BOKI` 或 `BOKI™`，**不要用 ®**。
4. **拿证后**：在核准类别内使用 `BOKI®`。
5. **被驳回**：15 日内复审；同时启动 Plan B（换标样/加图形/换类别）。
6. **拿到初审公告**后再加大市场投入最稳。

## 九、DBX 对标与许可证决策

### 9.1 DBX 的事实（公开信息）

| 项 | 结论 |
|:--|:--|
| 注册商标 | **未发现公开记录**：官网页脚无 ®、README 无商标声明、仓库无 TRADEMARK 文件 |
| 许可证 | **Apache-2.0**（GitHub 仓库标注） |
| 名称强度 | "DBX" 是拥挤的通用缩写（Databricks dbx、EventDBX、US 的 Dirty Boxing Championship 等），显著性弱 |
| 资助模式 | 捐赠 + 企业赞助 + 基础设施合作 + 联盟返佣 + 贡献者证书 |

> 未经中国商标局权威核验；如需 100% 确认，去 `sbj.cnipa.gov.cn` 搜 "DBX"。

### 9.2 我们与 DBX 的差异

| 维度 | DBX | BOKI |
|:--|:--|:--|
| 名称 | 通用缩写，难排他 | 臆造词，显著性高，易注册 |
| 商标 | 未注册 | **注册文字标 + 图形标** |
| 中文名 | 无 | 无（一致） |
| 许可证 | Apache-2.0 | **待定（见下）** |

### 9.3 许可证决策（与商标独立）

| 方案 | 优点 | 缺点 | 适合 |
|:--|:--|:--|:--|
| **Apache-2.0**（DBX 选择） | 采用门槛低、赞助商/企业友好、插件生态易繁荣 | 云厂商可拿去闭源托管 | 想快速做大生态与赞助 |
| **AGPL-3.0** | 防云厂商白嫖，改动必须开源 | 部分企业/赞助商顾虑 | 想守住内核 |
| **折中**：内核 AGPL-3.0 + SDK/官方插件 Apache-2.0 | 内核守住、生态开放 | 许可边界需写清楚 | 推荐默认 |

> 建议：**先按"内核 AGPL + SDK/插件 Apache"落地**；若后续发现赞助/采用受阻，再评估整体切换 Apache-2.0。商标与许可证互不影响，可分别决策。
