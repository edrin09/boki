Offline First

三层全离线：数据、语音、大模型

财务数据最敏感。BOKI 的核心能力全部可以在断网、内网环境运行，一个字节都不出机器。

数据离线

100% 本地

SQLite 单文件（WAL 模式）承载全部账务数据，一键备份 / 恢复；无任何外部服务依赖，财务数据不出机器。

financial.db · 单文件 · 零配置

语音识别离线

音频不上传

流式中文语音识别基于 sherpa-onnx（zipformer-zh int8，约 160MB）在本地完整解码，说话内容不经过任何服务器。

Security & Data Sovereignty

先把边界说清楚，再谈安全

我们不写「银行级 AES-256 零知识加密」这类话术。下面这张清单是当前代码的真实状态——做到的写做到，没做的明确标出来。

已经做到的

  • 部署边界在你手里单机 / 内网自部署，前后端同源单端口；无云端依赖、无第三方 SDK 回传，代码中不含埋点与遥测。
  • 口令不落明文口令以 bcrypt 加盐散列存储；JWT 短期令牌由本机签发，不经过第三方。
  • 授权双层校验RBAC 覆盖菜单级 + 操作级权限，前端指令与后端守卫同时校验，改前端绕不过去。
  • 多公司硬隔离业务表全部带 company_id，仓储层强制追加过滤；令牌内 companyId 由服务端签名，无法伪造。
  • 操作留痕登录、增删改、审核等动作本地留存操作日志，可查询、可清理。
  • 数据随时能带走全部数据就是一个 financial.db，可整目录拷走、一键备份、离线搬到另一台机器。

还没做到的（如实标注）

  • 数据库加密financial.db 当前是明文文件——拿到文件就能用任意 SQLite 工具直读。
  • 密钥 / 主密码登录尚无「免用户名口令、单 Key 解锁」与零知识主密码体系。
  • 敏感字段加密金额、往来单位等字段未做列级加密。
  • MFA 与备份加密当前仅单因子口令；备份出的 .db 文件本身未加密。
规划中 · 以插件形式交付

加密路线：主密码 / 恢复密钥解锁 → SQLCipher 库级加密 → 敏感字段列级加密。装不装由你决定，不装就保持现在的零配置体验。

Features

为「记账」这件事做到位

不做大而全的 ERP，只把小微企业每天要用的记账能力做扎实。

复式记账强校验

每张凭证至少 2 条分录，借方合计 = 贷方合计，前后端双重校验，不平衡无法保存；明细科目限制、辅助核算必填。

插件化架构

内核只留记账引擎，14 个官方插件即装即用、即卸即净；不装的插件在界面里不留一丝痕迹。

离线私有化

数据 / 语音 / 大模型三层全离线：SQLite 单文件、本地 OCR、本地流式 ASR、可选本地大模型，内网 / 断网环境完整可用。

多公司隔离

一个账号管理多家记账公司，所有业务表带 company_id 全链路隔离，令牌内公司标识由服务端签名保证不可伪造。

票据智能记账

上传电子发票 PDF / 扫描件，自动解析类型、金额、税额、购销方；sha256 去重、归类规则，确认后一键生成凭证。

AI 会计员

AI 插件提供模型配置（本地 / 云端可选），语音插件支持自然语言查账记账，悬浮入口即问即答。

Architecture

内核做减法，生态做加法

后端业务模块从 29 个收口到 8 个，前端页面从 45 个收口到 18 个——内核只保留记账必需的引擎。

  • 1
    内核 = 复式记账引擎科目、凭证、期初、公司上下文、权限种子——零插件状态下仍可完成「登录 → 建账套 → 记账」完整闭环。
  • 2
    插件运行时manifest 校验 → 动态注册后端 AppModule / 前端路由 / 菜单 / 插槽 → 静态资产注入，全程热插拔。
  • 3
    插件市场系统内浏览 catalog、查看详情、安装 / 卸载 / 启停；卸载时按需保留或清除插件数据。
  • 4
    依赖与安全插件声明依赖自动带上；卸载被依赖插件会被拦截；权限点逐插件声明，越权访问被守卫拦截。

单个 BOKI-Setup.exe。未装 Node、未装数据库、不能联网的机器装完即用；那台机器同时充当局域网服务器。

GitHub Releases ↓ Gitee 发行版

源码运行

两个终端跑起后端（3000）与前端（5173），适合开发、二次开发与自备 Linux / 云主机部署。

npm i && npm run dev

离线模型

OCR 模型约 25MB、流式语音识别约 160MB，首次使用前下载；缺失时服务照常启动，仅识别 / 语音类功能提示未就绪。

npm run models:fetch && npm run models:fetch-asr
